# Data Dictionary

| Field | Description |
|---|---|
| `unitid` | Unique institution identifier |
| `institution_name` | Name of the institution |
| `state_cd` | State abbreviation |
| `sector_name` | Institution sector |
| `SPORTSCODE` | Sport identifier |
| `SUM_PARTIC_MEN` | Number of male participants |
| `SUM_PARTIC_WOMEN` | Number of female participants |
| `TOTAL_OPEXP` | Total operating expenses |
| `TOTAL_REVENUE_ALL` | Total reported revenue |
| `TOTAL_EXPENSE_ALL` | Total reported expenses |
